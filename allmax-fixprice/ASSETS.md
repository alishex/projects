# Original visual assets

Everything under `public/assets/` is either (a) the user's own supplied ALLMAX Fix Price logo files, used unedited, or (b) original, hand-authored inline SVG line art — not photographs, and not AI-generated raster images. No clothing/model photography is used anywhere in the placeholder catalog.

- `mark.png`, `lockup-on-white.png` — the two logo files as supplied by the user, copied byte-for-byte. `mark.png` (transparent background) is used as the favicon and the header/hero brand mark, since it renders correctly on both the light and dark theme. `lockup-on-white.png` has an opaque white background baked into the file and is used only for the `og:image` social-preview tag, where a white card background is expected regardless of theme — it is never placed directly on the adaptive page background. Neither file has been cropped, recompressed, or otherwise edited.
- `cat/*.svg` (14 files) — one abstract line-icon per category (kurtka, koylak, kardigan, futbolka, shim, kostyum, dvoyka, gilet, oyoq-kiyim, remen, hamyon, sumka, aksessuar, vetrovka), geometric garment/accessory silhouettes in a consistent single-stroke style. The exact same path data is inlined directly into `public/app.js` (the `CATEGORIES`/`ICONS` table) so the customer-facing storefront can recolor each icon to match the active theme (`stroke="currentColor"`, set via CSS) instead of a fixed color baked into a file; the on-disk SVG copies exist so the admin panel's plain `<img>` product thumbnails always have something real to load.

**Every demo product's "photo" is its category icon**, rendered inline so it adapts to light/dark automatically. This is explicitly placeholder, not product photography — the storefront marks the catalog as a demo (`DEMO_MODE=true`) specifically because of this, exactly like the sibling intim-shop-parfume project before its catalog was replaced with real photos.

Before taking real orders: replace each product's image through the admin panel (`/admin` → Mahsulotlar → Tahrirlash → Rasmlar) with real photography of your actual stock — once a product has an uploaded `/uploads/...` image, the storefront automatically switches that product from the inline icon to the real photo (see `visual()` in `public/app.js`) — then set `DEMO_MODE=false` in `.env`.
